# Optional exact stroke reuse

The shared renderer can select `--native-stroke-coverage-cache`; `--native-glyph-coverage-cache` independently selects the earlier alpha cache. Both default off, only default/Home receives definitions; return-to-default does not. Build metadata records selection, exact source hashes (including new header), capacity and host—not target—allocation sizes. No historical board is silently opted in.

Stroke cache stores existing four-sample coverage counts0–4 in three bits each. Keys are transformed endpoints relative to clipped grid origin, endpoint delta, radius and clipped grid dimensions. Colors and destination pixels are not keys/data: hit replay performs original ordered RGB565 blend and `at()` custody checkpoints. No stroke/arc simplification, thumbnail scaling, frozen animation or changed time progression. Exact hash collisions compare the complete key. The existing wide arithmetic and row-bounded raster remain the miss/fallback path. Empty/oversized cache grids fall back. Large sparse strokes above4KiB cached size are deliberately not stored; they otherwise evict many small reusable segments.

One lazy optional allocation is102,408B on64-bit host:64KiB packed coverage,1024 entries,2048 hash slots, counters. Target total awaits native layout receipt. Allocation failure uses original renderer and is not retried until explicit release. Home teardown releases it through existing raster-cache release. Selecting both caches adds175,120B host total, alongside existing~927KiB picker pixels and display buffers. No claim target memory is sufficient. Arena/entry exhaustion drops optional metadata and resumes population; no provider ownership is retained. Cache is invocation-local/serialized, not concurrent shared state. Terminal partial misses are never published.

## Geometry admission successor

Both optional caches now use a small shared reuse hint: actual canvas construction observes width/height; three matching observations within eight canvas constructions admit reuse.32 bounded hashed geometry entries cost516B host static storage when either cache is selected. Hash collision/expiry merely denies reuse; it never changes pixels or evicts existing coverage entries. Picker outer destination and each actually rerendered card are separate observations; tests assert that relation. This is not a display-frame counter or a per-device/face rule. The first two cold observations render normally. Geometry changes bypass lookup/insertion without flushing stable entries. Constant specializations of one raster implementation remove per-pixel cache branches on bypass.
