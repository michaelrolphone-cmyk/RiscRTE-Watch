# Optional native glyph coverage cache

Experimental, unselected by default. `WATCH_NATIVE_COVERAGE_CACHE` adds one lazy optional allocation containing64KiB of coverage and128 bounded metadata entries. Host64-bit allocation is72,712B (7,168B entrymetadata); actual target size must be measured at target qualification. Failed allocation is tried once per invocation/release cycle and falls through to the original renderer. `nova_watch_raster_cache_release()` frees it at Home teardown and is idempotent. This is additional to the existing466 picker cache's927,408 pixelbytes and display buffers; it is not a claim that the target has sufficient free heap. Original scope has no new per-frame heap allocation or mandatory largeBSS.

Keys are immutable sourcebank+glyphoffset, dimensions, exact scale, clipped-relative Q8origin and clipped outputdimensions. Packed glyph scratch is deliberately not identity. Native Nova masks have stable owned immutable addresses after asset preparation. Entries contain pre-opacity alpha only. Every hit replays blending against current destination in original order and uses the same `at()` custody checkpoint path; neither color nor framebuffer data is cached. Misses are published valid only if the canvas did not fail. Arena/metadata exhaustion clears the optional cache; oversized glyphs render normally. No provider lease is retained. Current renderer is single invocation/serialized; this is not a concurrent shared cache.

Packed glyph decompression still occurs before lookup; a hit does NOT bypass compressed source validation/decode. Whole-font decode caching is a separate candidate. Cache slot/arena churn makes this ineffective for moving picker in measured host workload; do not advertise a picker fix.

## Qualification

`tests/native_coverage_cache_test.c` includes real renderer and compares fullbuffers/cache-off versus on, including102 face/state pairs,600 coverage key/background/opacity/scratch reuse cases,14 callbackfault pairs,50 moving picker pairs, plus OOM/fallback/release/retry checks. Normal and ASan+UBSan passed. ASan leak detection disabled due environmentptrace; allocation/free behavior asserted directly. Hash/callback parity against untouched installed renderer additionally checked31 cases; cache-disabled same31 hashes/callback counts pass. Full selected target, targetheap and product-runtime qualification not performed here.

Normal same-process host examples: defaultface1.424→1.351ms; face22 1.234→.902ms; face29 .222→.135ms. Moving picker1.129→1.141ms (no gain),516hits/3236misses, final12,948B/86entries. DesktopCPU/zero-I/O callbacks are not deviceFPS. Earlier warm calendar/Context workloads improved~43%; defaultface remains dominated by line/arc work (658segments/~87,400 candidatepixels atsecond49). Never sum nested timing instrumentation or infer universal frame-rate gains.

Next reusable geometry candidate is exact stroke coverage keyed by scaled endpoints,width and destinationclipping, replayed in existing segmentorder. Most default arc-prefixsegments stay invariant while only the finalsegment advances; circles/simplified arcs would not preserve segmented-overlap pixels. A bounded memory budget must compete with, not silently stack on, this cache. No such primitive cache implemented in this change.
